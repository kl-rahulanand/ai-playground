INC-205 — Search results empty for a subset of users

At 14:22 UTC, support reported that some users see an empty search page instead
of results. No error alert fired.

No deployment went out in the last 24 hours.

The search service CPU is normal. A cache node (search-cache-3) was reported as
"degraded" by the infra dashboard at an unknown time.

A feature flag, search_ranking_v2, was enabled for 10% of users two days ago.

The incident director asks:

What is the likely cause, and what should we check first?

Known limitation: this incident brief contains initial reports, not a confirmed
timeline or root cause. Affected-user overlap with the feature flag has not been
measured yet.
